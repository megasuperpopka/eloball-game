# Иконки приложения

Сюда нужно положить три PNG-картинки:

- `icon-192.png` — 192×192 px (для PWA, иконка на главном экране)
- `icon-512.png` — 512×512 px (для PWA и Android-сборки)
- `icon-512-maskable.png` — 512×512 px с запасом по краям (Android их обрезает в круг/квадрат)

## Как сделать быстро

1. Открой любой редактор (Photoshop, Figma, Paint.NET, GIMP) или онлайн — например, [pwabuilder.com/imageGenerator](https://www.pwabuilder.com/imageGenerator).
2. Загрузи любую квадратную картинку — например, логотип EloBall: мяч + буквы.
3. Скачай готовый набор PNG разных размеров.
4. Скопируй три нужные сюда (рядом с этим README).

Пока иконок нет — игра как PWA всё равно установится, но Android покажет дефолтный значок «глобуса». Не страшно.

## Совет

Делай иконку с прозрачным фоном или однотонной заливкой `#070b14` — этот же цвет используется в `manifest.webmanifest` как `background_color` и `theme_color`.
